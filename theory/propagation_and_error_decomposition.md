# Propagation and error decomposition

The hybrid-chain telescoping construction replaces FP kernels by quantized kernels one step at a time and bounds endpoint distortion by adjacent hybrid distances. Coordinate-union refinements correct repeated changes, while last-change attribution separates exact endpoint contribution from predictive bounds.

For mechanism analysis, the project separates split incidence from conditional downstream damage and decomposes terminal changes into retained seed differences, repaired differences, and newly created differences. Raw telescoping is valid for its specified coupling but can be quantitatively vacuous; the report does not transfer that sum to arbitrary couplings.
