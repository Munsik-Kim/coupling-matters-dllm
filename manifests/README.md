# Manifests

- `GITHUB_FILE_MANIFEST.json` / `GITHUB_SHA256SUMS.txt`: active public GitHub-tree integrity records.
- `ZENODO_*`: immutable ledgers from the canonical Zenodo v1.0.0 archive; they describe that original package, not the reorganized GitHub tree.
- `PRIVATE_TO_PUBLIC_FILE_MAP.csv`: additional copied source with before/after hashes.
- `OMITTED_LARGE_ARTIFACTS.csv`: public ledger of intentionally omitted large data.
