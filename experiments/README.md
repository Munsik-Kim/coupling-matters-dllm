# Experiment map

The public tree is organized by scientific role rather than the private work-package directory layout.

- `metric_localization_negative/`: model-free frozen-metric and witness negative investigation.
- `transport_calibration_negative/`: transport-weighted clipping negative investigation; reproduction may need external compact inputs.
- `prompt_population/`: independent PyArrow headline checker for the declared prompt-population certificate.
- `bit_scaling/`: independent six-bit-scaling headline checker.
- `temperature_extension/`: independent count-based healing-estimand checker.

Fixed-suite CERT-3, SMDM/GSM8K, lifted-sampler, and sampler-microaudit evidence is published as compact material under [`artifacts/`](../artifacts/). Their full GPU runners and large raw archives are intentionally omitted. No empty decorative directories are created.
