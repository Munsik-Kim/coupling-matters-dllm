# Reusable tools

- `event_addressed_rng/cmc_coupling.py`: deterministic semantic-event RNG and categorical/product coupling primitives.
- `coupling_audit/`: CPU-only marginal, diagonal-preservation, branch-order, and product-hazard tests.
- `split_damage_analysis/`: finite-state residual-mass, coordinate-change, and statistical-family regression tests.
- `raw_to_claim_audit/`: methodology and links to the frozen clean-room/public audit artifacts.

These utilities preserve the audited implementation contracts. Reuse outside monotone copy-only masked decoding requires a fresh theorem/applicability audit.
